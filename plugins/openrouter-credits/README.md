# OpenRouter Credits (RisuAI 플러그인)

OpenRouter 크레딧 잔량을 실시간으로 조회해 화면에 표시하는 API v3.0 플러그인입니다.

## 기능

- **잔량 배지**: 채팅 영역 왼쪽 위(기본값)에 `● OpenRouter $12.34` 형태로 상시 표시. 클릭하면 상세 패널이 열립니다.
  - 초록: 정상 / 주황: 경고 기준 미만 / 빨강: 0 이하 / 회색: 조회 오류
- **자동 갱신**: 설정한 주기(기본 60초)마다 조회하고, AI 응답이 끝날 때마다 4초 뒤 한 번 더 조회합니다. 탭이 숨겨져 있을 때는 쉬고, 다시 보이면 바로 갱신합니다.
- **상세 패널**: 계정 크레딧(구매/사용/잔여), API 키 한도·잔여, 오늘/이번 주/이번 달 사용량. 설정 메뉴의 `OpenRouter 크레딧`으로도 열 수 있습니다.

## 설치

1. RisuAI → 설정 → 플러그인 → 플러그인 가져오기에서 `openrouter-credits.js`를 선택합니다.
2. 플러그인 설정에 **OpenRouter API 키**를 입력합니다.
   플러그인은 보안상 RisuAI 본 설정에 저장된 OpenRouter 키를 읽을 수 없어서 따로 넣어야 합니다.
3. 처음 실행할 때 메인 화면 접근 권한(`mainDom`)을 묻습니다. 거부하면 배지 대신 채팅 메뉴에 잔량 항목이 생깁니다.

## 설정 항목

| 항목 | 설명 |
| --- | --- |
| OpenRouter API 키 | 조회에 쓸 키 (`sk-or-v1-...`) |
| 자동 갱신 주기 (초) | 0이면 60초, 최소 10초 |
| 경고 기준 잔량 ($) | 이 금액 미만이면 주황색 (비우면 1) |
| 표시 위치 | 화면 배지 / 채팅 메뉴 / 햄버거 메뉴 |
| 배지 위치 | 채팅 영역의 네 모서리 중 선택 (기본: 왼쪽 위). 채팅 화면이 없을 때는 숨겨집니다 |

## 잔량 계산 방식

두 엔드포인트를 동시에 호출합니다.

- `GET /api/v1/credits` → `total_credits - total_usage` = **계정 잔여 크레딧** (우선 표시)
- `GET /api/v1/key` → 키 한도(`limit`, `limit_remaining`)와 기간별 사용량

키 권한 때문에 `/credits`가 실패하면 키의 `limit_remaining`으로 표시하고, 키에 한도도 없으면 누적 사용액을 보여줍니다.
OpenRouter 쪽 사용량 집계는 요청 후 몇 초~수십 초 늦게 반영될 수 있습니다.
